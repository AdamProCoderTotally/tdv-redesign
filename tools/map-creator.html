MAP DETAILS

TOOLS

PAINT gives any tile a custom colour (use RESET TILE to clear it)
PATH: click tiles in order — enemies walk from the first point to the base. Right-click removes the last waypoint. WATER/HILLS/PAINT: drag to paint.

CUSTOM TEXTURE (optional)

Tiled over the whole map in-game (weathering, grass texture...). Auto-shrunk to 128×128.
Edit view is top-down. In-game it renders isometric — use EXPORT, paste into map.js, and check the map-select screen for the real look.

MAP PALETTE

Change any ground colour. Only colours you change are exported.

EXPORT

1. Click EXPORT GAME CODE → 2. Copy the block → 3. Paste it into the CUSTOM MAPS — PASTE ZONE at the bottom of js/map.js → 4. Launch the game. Your map appears in the map select screen next to TEST PLACE.
